tradingchango.com
Problema

Plataforma end-to-end con scrapers automáticos en Python/Playwright, base de datos relacional en Supabase y dashboard interactivo en React. Hoy indexa +50.000 ítems de precios con un 99.9% de uptime.
Stack
Python Playwright Supabase / Postgres React TypeScript
